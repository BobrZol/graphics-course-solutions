Проверил на GTX 1660 Ti, 1280×720, Debug с Vulkan-валидацией. GPU timestamp-запросы измеряют три compute-прохода: минимум и максимум, гистограмму и экспозицию. После 30 кадров прогрева усредняются 120 кадров.

С shared memory получилось 0.099 мс, с глобальными атомарными операциями 0.310 мс. В этом замере shared memory быстрее примерно в 3.1 раза. Повторить: EXPOSURE_BENCHMARK=1 ./build/tasks/model_bakery/renderer/terrain. Результаты выводятся в терминал.

Яркость считается в линейном RGB: 0.2126 R + 0.7152 G + 0.0722 B. Гистограмма содержит 100 равномерных интервалов логарифма яркости. Логарифм позволяет учитывать и тёмные, и яркие области. Экспозиция выбирается по геометрическому среднему, затем плавно меняется со временем. После экспозиции используется Reinhard: x / (1 + x).

HDR хранится в B10G11R11_UFLOAT. Восемь бит на канал в бэкбуфере сами ограничивают и квантуют значения, отдельное округление в шейдере не требуется. У Vulkan-бэкбуфера есть также служебный альфа-канал. Auto-gamma выключена, sRGB-кодирование выполняется перед LUT. Если поверхность имеет формат sRGB, перед записью выполняется обратное преобразование, чтобы не применить гамму дважды.

LUT построена из цветовой таблицы source.png и её обработанной в ImageMagick версии graded.png. Красный канал немного усилен, синий ослаблен, насыщенность слегка увеличена. Скрипт build_lut.py усредняет цвета внутри ячеек и заполняет пустые ячейки ближайшими заполненными. Текстура 32×32×32 RGBA8 использует линейную фильтрацию. Тон-маппинг и цветокоррекция переключаются независимо.
